# Python Number Comparison Tool

This is a simple beginner Python project that compares two numbers using loops and conditions.

## Features
- Compare two numbers
- Infinite loop using while True
- Exit option using "exit"
- Handles basic user input

## Concepts Used
- while loop
- if-elif-else conditions
- input handling
- type conversion (string to int)

## How to Run

```bash
python number_comparison.py
```

## How It Works
1. User enters first number
2. User enters second number
3. Program compares both numbers
4. Displays which number is greater or if equal
5. Type "exit" to stop program
